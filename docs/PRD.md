## 1. 목표와 성공조건

### 1-1. 목표
- **한 줄 정의**: 전국 45개 지역의 실시간 날씨를 기반으로, 상황별 3가지 스타일(캐주얼·출근·스포티)의 부위별 맞춤 코디와 가방 소지품을 귀여운 비주얼로 제안하는 인터랙티브 웹 앱
- **해결할 문제**: "오늘 날씨에 대체 뭘 입어야 하지?"라는 아침의 고민 시간을 5초 이내로 단축
- **핵심 가치**:
  1. **정확성**: 체감온도, 일교차, 강수확률, 풍속, 자외선 등을 종합 분석한 과학적 추천
  2. **다양성**: 단순 날씨 텍스트가 아닌, 출근룩·일상룩·편한룩 등 상황에 맞는 선택권 제공
  3. **재미와 비주얼**: 현재 날씨가 생생하게 느껴지는 애니메이션 배경과 살아 숨 쉬는 캐릭터 옷장

### 1-2. 제공 범위

|---|---|

### 1-3. 성공 조건 (품질 판정 기준)
- [x] 접속 시 저장된 도시(기본: 서울)의 실시간 날씨가 1초 내외로 로드된다.
- [x] 전국 45개 도시가 권역별로 일목요연하게 분류되어 선택 가능하다.
- [x] 스타일 탭(데일리 캐주얼, 출근·모던, 스포티·편안) 클릭 시 캐릭터와 코디가 즉시 매끄럽게 교체된다.
- [x] 부위별(상의, 하의, 아우터, 신발, 소품)로 실질적으로 입을 수 있는 아이템이 추천된다.
- [x] 비·눈·강풍·큰 일교차 발생 시 알맞은 주의 팁과 소지품 배지(우산, 방한화, 겉옷 등)가 노출된다.
- [x] 체감온도 게이지 바의 표정 이모지와 바늘이 체감 기온 위치로 정확히 슬라이딩된다.
- [x] 모바일(360·390px) 세로 뷰포트 에뮬레이션에서 가로 넘침 없이 표시되며, PC에서도 480px 중앙 컨테이너로 표시된다. (실기기 확인은 아래 미검증 항목)
- [x] `prefers-reduced-motion` 환경에서는 과도한 애니메이션이 차단된다.
- [x] 네트워크 단절 시 오프라인 안내 화면이 표시된다. 서비스 워커 덕분에 오프라인에서 앱을 다시 열어도 화면이 뜬다. (헤드리스 Chrome 확인)
- [x] AI 한마디가 `/api/comment`를 통해 제공되고, 실패 시 규칙 기반 코멘트로 대체된다.
- [x] 프로덕션 빌드에서 매니페스트와 서비스 워커가 등록되며(Chrome 확인, 설치 가능 조건 오류 0건), `/api/*`는 캐시되지 않는다.
- [x] AI가 아닌 규칙 기반 한마디에는 "AI 한마디" 대신 "오늘의 한마디"로 표시해 출처를 구분한다.
- [x] 추천 엔진 경계값·배지 규칙과 날씨 파싱을 자동 테스트(`npm test`, 18건)로 검증한다.
- [x] 스타일 탭 전환 지연 100ms 이내 (에뮬레이션 중앙값 22~39ms)
- [x] [오늘 코디 카드 공유] 버튼이 현재 선택한 스타일 기준 1080×1350 PNG를 생성한다(공유 시트 미지원 시 다운로드).
- [ ] 모바일 실기기에서 홈 화면 설치 UI와 Web Share 시트 동작을 확인한다. (미검증, HTTPS 배포 후 가능)
- [ ] LCP 1.5초 이내: 일반 환경 중앙값 약 1.35초로 충족하나 편차가 크고(0.7~2.2초), Slow 4G + CPU 4x 에뮬레이션에서는 약 1.85초로 미달. 실기기 미측정

### 3-1. 주요 컴포넌트 구성
1. **`ThemeBackground`**:
   - 현재 기상 코드(`clear`, `partly`, `cloudy`, `fog`, `drizzle`, `rain`, `snow`, `storm`)에 반응하는 풀스크린 배경.
   - 비 내리는 효과(`anim-rain`), 눈 내리는 효과(`anim-snow`), 번개(`anim-lightning`), 안개 흔들림(`anim-fog`), 태양 회전 등 CSS 애니메이션 탑재.
   - 어두운 날씨 테마 시 텍스트 명도 및 가독성을 자동 보정(`DARK_THEMES`).
2. **`TopBar` (`AppHeader` + `CityBar`)**:
   - 상단 타이틀, 현재 날짜(한국어 포맷: `M월 D일 (요일)`).
   - 전국 6대 권역 45개 도시를 `<optgroup>`으로 묶은 커스텀 셀렉트 드롭다운 + 회전 애니메이션 새로고침(↻) 버튼.
3. **`WeatherStage`**:
   - 날씨 이모지 & 상태 텍스트, 대형 기온 타이포그래피.
   - 체감기온, 최고/최저 기온.
   - **체감온도 표정 게이지(`FaceGauge`)**: -10℃(한파)부터 35℃(폭염)까지의 컬러 바 위에 현재 체감온도 핀과 기온별 표정 이모지(🥶, 😌, 😊, 😎, 🥵)가 부드럽게 위치.
4. **`WardrobeCard` (핵심 코디 영역)**:
   - **스타일 세그먼트 탭**: `데일리 캐주얼` / `출근·모던` / `스포티·편안`.
   - **말풍선**: 선택된 스타일 코디 조언 및 AI 한마디 타이핑 애니메이션 출력.
   - **인터랙티브 옷장 스테이지**: 원목 옷장 문 열림 연출(`anim-door`), 캐릭터 클릭 시 앙증맞은 흔들림과 랜덤 리액션 대사 출력.
   - **코디 상세 그리드**: [아우터], [상의], [하의], [신발], [포인트/소품]의 실물 매칭 아이템 칩.
   - **날씨 맞춤 팁 배너**: 강풍, 비, 눈, 일교차 등에 대응하는 스마트 조언 배너.
5. **`BagCard`**:
   - 가방에 챙겨야 할 필수 준비물(우산, 겉옷, 방한용품 등)을 귀여운 스티커 틸트(`anim-sticker`) 형태로 시각화.
6. **`MiniInfo`**:
   - 강수확률(💧), 풍속(🌬️), 자외선 지수(☀️)를 3열 그리드로 깔끔하게 요약 제공. (위험 수치 시 강조 컬러 적용)
7. **`AppFooter`**:
   - 마지막 데이터 갱신 시각 및 데이터 출처 안내.
8. **`ShareButton`** (`WardrobeCard` 하단, `_lib/share-card.ts`):
   - 현재 선택한 스타일의 도시·날짜·체감온도·부위별 코디·팁·소지품 배지를 Canvas로 1080×1350 PNG로 렌더링.
   - `navigator.share`로 파일 공유를 시도하고, 미지원/실패 시 PNG 다운로드로 대체.
9. **`ServiceWorkerRegister`** (`layout.tsx`):
   - 프로덕션 환경에서만 `/sw.js` 등록. 정적 파일은 캐시 우선, 페이지 이동은 네트워크 우선(실패 시 캐시된 셸), `/api/*`와 외부 API는 캐시 제외.

1. **우산**:

   - 강수확률 30% ~ 59% → `🌂 접이식 우산 추천`
2. **눈/결빙**:
   - 눈 코드(71~86) → `❄️ 미끄럼 주의 신발`, 캐릭터 손에 장갑(🧤) 착용, 신발 부츠(🥾) 변경

   - 당일 최고기온 - 최저기온 ≥ 10℃ → `🧣 일교차 커요, 겉옷 챙기기` 배지 및 레이어드 팁 노출
4. **강풍**:
   - 풍속 ≥ 30 km/h → `🌬️ 바람 강해요, 바람막이 추천` 배지 및 모자 날림 주의 팁 노출
5. **자외선**:
   - UV 지수 ≥ 6 → `🧴 자외선 강해요, 선크림·모자` 배지, 캐릭터 볼캡(🧢) 착용

## 6. 예외 처리 및 안정성 정책

| 상황 | 원인 | 시스템 대응 |
|---|---|---|
| **E-1. 네트워크 지연** | 기상 API 호출 10초 초과 | AbortController로 요청 취소 후 오류 화면 + [다시 시도] 버튼 제공 |
| **E-2. 오프라인 상태** | 인터넷 연결 단절 | `navigator.onLine` 감지 후 친절한 오프라인 전용 화면 표시 |
| **E-3. 데이터 누락** | 체감온도 또는 특정 수치 결측 | 체감온도 누락 시 현재 기온으로 자동 대체, 누락 항목은 `-` 표기 후 정상 추천 지속 |
| **E-4. 도시 변경 경합** | 도시를 빠르게 연속 선택 | Request ID 체킹을 통해 마지막으로 선택된 요청의 결과만 화면에 안전하게 렌더링 |
| **E-5. 로컬스토리지 오류** | 시크릿 모드/쿠키 차단 | 에러 무시(Silent Fail) 후 기본 도시(서울)로 정상 동작 유지 |
| **E-6. 접근성 지원** | 모션 민감 사용자 | OS 차원의 `prefers-reduced-motion` 감지 시 모든 배경 흔들림/회전 애니메이션 즉시 정지 |
| **E-7. AI 응답 실패** | Gemini 타임아웃/429/키 누락/토큰 한도로 잘린 응답, 서버의 날씨 조회 실패, 잘못된 도시 ID | 잘못된 도시 ID는 400. Gemini 실패·잘린 응답은 서버가 규칙 기반 코멘트로 대체(2분 캐시 후 재시도). 서버 날씨 조회 실패는 503으로 응답해 클라이언트가 자체 규칙 코멘트를 사용. 규칙 기반 문구는 "오늘의 한마디"로 표시하며 화면은 항상 정상 표시 |
| **E-8. 공유 이미지 생성 실패** | Canvas 미지원, 공유 시트 거부 | 공유 취소는 조용히 종료, 공유 실패 시 PNG 다운로드로 대체, 생성 오류 시 안내 문구 표시 |
